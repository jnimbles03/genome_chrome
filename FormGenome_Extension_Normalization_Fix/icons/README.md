# Extension Icons

You need to add PNG icon files here:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

For now, you can create simple icons using any image editor or online icon generator.

Quick option: Use https://www.favicon-generator.org/ to create icons with the text "FG" or a clipboard emoji 📋.

Recommended colors:
- Background: #667eea (purple)
- Text: #ffffff (white)
