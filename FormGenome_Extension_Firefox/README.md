# Form Genome Chrome Extension

An intelligent AI assistant that analyzes PDF forms directly in your browser.

## 🚀 Installation Instructions (Developer Mode)

Until the extension is published to the Chrome Web Store, you can install it manually by following these steps:

1.  **Download** this folder (`FormGenome_Extension_Clean`) to a safe location on your computer.
2.  Open **Google Chrome**.
3.  Type `chrome://extensions/` in the address bar and press Enter.
4.  Enable **Developer mode** using the toggle switch in the top right corner.
5.  Click the **Load unpacked** button that appears in the top left.
6.  Select the `FormGenome_Extension_Clean` folder.
7.  The **Form Genome** extension card should appear in your list.

**Tip:** Click the "Puzzle Piece" 🧩 icon in your Chrome toolbar and **Pin** the Form Genome extension for easy access!

---

## 📖 How to Use

### 1. Dashboard View
- Click the extension icon and select **"Open Dashboard"** (or **"Team Dashboard"**).
- This opens a full-screen view of all your analyzed forms.
- **New Feature:** You can now see a sortable, filterable **Data Table** with over 30 attributes (Complexity, Signatures, etc.).
- **Drag & Drop:** Reorder columns by dragging headers to customize your view.

### 2. Single PDF Analysis
- Navigate to any PDF file in your browser.
- Click the extension icon.
- Click **"Analyze This PDF"**.
- Takes ~10-15 seconds. Results will appear in the popup.

### 3. Batch Analysis
- Navigate to a webpage listing multiple forms (e.g., a bank's form center).
- Click the extension icon.
- It will automatically detect PDF links and list them.
- Select the forms you want and click **"Analyze Selected"**.
- Watch the progress bar as it processes them in the background!

## ✨ Features
- **AI-Powered Analysis**: Uses Gemini Flash and Claude Opus for deep understanding.
- **Smart Detection**: Automatically identifies PDF links on webpages.
- **Persistent History**: Saves all your analyses locally and syncs them to the Team Dashboard.
- **Excel Export**: Export your entire analysis history to CSV from the Dashboard.
